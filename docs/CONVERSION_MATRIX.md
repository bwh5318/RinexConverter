1. `antenna-phasecenter-code-not-representable`: ANTENNA: PHASECENTER names an observation code (rinex305.txt Table A2 p.53); a code the target version does not define (or of a system it lacks) has no record there
2. `data-text-dropped`: --lenient only (PLAN §1 clause 9: data-level damage is refused by default; --lenient repairs what it can and reports each repair): text in columns no field of its record covers has no observation type or meaning (rinex211.txt Table A2: 80-column records, 5 fields of F14.3,I1,I1 per line, event lines without a satellite list; rinex305.txt Table A3 p.59 and rinex_4.02.txt Table A3: one field per declared type, reserved 6X), so it is dropped, one count per line
3. `epoch-emptied-by-system-removal`: an epoch whose only satellite records belong to a dropped system, or (RINEX 3/4 targets) have no type the target defines under their list (each type claimed obs-code-not-representable; a RINEX 3/4 record holds the fields of its system's SYS / # / OBS TYPES only: rinex305.txt Table A3 p.58), has nothing left to hold; between RINEX 2 and 3/4 a type list is rebuilt from the columns that hold data, so a record blank in every column has none either
4. `event-emptied`: a flag-4 event ('header information follows', rinex305.txt Table A3 p.59-60) whose records were all unrepresentable or deprecated, or described only a system or phase entry the target drops (QZSS is defined from 3.02: absent from rinex301.txt), is dropped
5. `event-record-foreign-dropped`: the same records inside an event (flag 4 'header information follows', rinex211.txt Table A2)
6. `event-record-not-representable`: header records inside flag 2-5 events follow the header tables (rinex305.txt §5.3.2)
7. `flags-on-missing-value-dropped`: Compact RINEX 1.0 cannot hold LLI/SSI on a blank RINEX 2 observation (rnx2crx.c; docs/HATANAKA.md); only with Hatanaka output
8. `header-record-foreign-dropped`: a SYS / SCALE FACTOR, SYS / PHASE SHIFT, GLONASS SLOT / FRQ # or GLONASS COD/PHS/BIS record in a version that does not define it (rinex211.txt Table A1 has none; rinex300.txt Table A1 no SYS / PHASE SHIFT or GLONASS records; rinex301.txt Table A1 no GLONASS COD/PHS/BIS) means nothing to that version's readers: not interpreted, so not written to another version

10. `header-record-not-representable:LICENSE OF USE`: defined only from 4.00 (rinex_4.00.txt Table A2); a same-version conversion of a file that already has it carries it
